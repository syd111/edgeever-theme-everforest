# Everforest 主题（EdgeEver）

一款用于 EdgeEver 的亮/暗色主题插件。

## 安装

打开 EdgeEver 的「插件市场」，在「GitHub 仓库或 Manifest 地址」输入框中粘贴：

`https://github.com/syd111/edgeever-theme-everforest`

点击「安装」，然后在插件列表中启用该主题。

## 配置

主题令牌写在 `manifest.json`，包含 `light` 与 `dark` 两组配色。修改后提交并推送，在桌面端重新安装或更新即可生效。

当前配色为测试色板，可按需调整 `manifest.json` 中的颜色令牌。
